
# 🌍 GLOBAL MARKET
### One Platform. Endless Opportunities.

**Discover. Advertise. Connect. Grow.**

Global Market is a digital marketplace designed to connect businesses, entrepreneurs, sellers, service providers, and customers through one convenient online platform.

The platform provides businesses and individuals with an opportunity to showcase their products and services, publish advertisements, reach potential customers, and grow their visibility online.

Customers can explore different categories, discover products and services, and connect with businesses from one central marketplace.

---

## 📌 About the Project

Global Market aims to make buying, selling, advertising, and discovering services easier by bringing different business opportunities together in one digital environment.

Whether you own a small business, operate an established company, provide professional services, or simply want to discover products, Global Market is designed to help you make meaningful connections.

## 🎯 Our Mission

To create an accessible and reliable digital marketplace that empowers businesses, supports entrepreneurs, connects customers with opportunities, and simplifies product and service discovery.

## 🌟 Our Vision

To become a trusted marketplace where businesses and customers can connect, discover opportunities, and grow together locally and internationally.

## ⚙️ Getting Started

To run the project locally:

1. Clone the repository.

```bash
git clone https://github.com/wesambainnocent2401/GLOBAL-MARKET.git
```

2. Open the project folder.

```bash
cd GLOBAL-MARKET
```

3. Open the project using a local development server or your preferred code editor.

4. Configure the required Appwrite project settings.

5. Open `index.html` through your local development server.

### Appwrite Configuration

Global Market uses Appwrite for backend functionality.

You will need to configure:

- Appwrite endpoint.
- Project ID.
- Database ID.
- Required database tables and permissions.
- Authentication settings.
- Storage buckets and permissions.

**Security:** Never publish Appwrite API keys, private credentials, or other secret information in frontend JavaScript files.
